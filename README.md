# 景辰云贸 - 水杯跨境电商网站

![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Deployed-brightgreen)

专业的水杯跨境电商公司官网，专注于将中国优质水杯销往全球市场。

## 🌍 项目概述

**景辰云贸**是一家专注于水杯类产品的跨境电商公司，主要业务是将中国制造的健康水杯销售给海外客户。我们提供从市场调研、产品认证到物流配送的一站式解决方案。

## 🛠️ 技术栈

- **前端框架**: React 18 + TypeScript
- **样式**: Tailwind CSS
- **构建工具**: Vite
- **路由**: React Router DOM
- **国际化**: i18next
- **部署**: GitHub Pages

## 🚀 快速开始

### 本地开发

```bash
# 克隆项目
git clone https://github.com/你的用户名/cross-border-ecommerce.git

# 进入项目目录
cd cross-border-ecommerce

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 构建生产版本

```bash
# 构建项目
npm run build

# 预览构建结果
npm run preview
```

## 🌐 部署

本项目使用GitHub Pages进行免费部署：

1. 将代码推送到GitHub仓库
2. 在仓库设置中启用GitHub Pages
3. 选择部署分支（通常是`gh-pages`或`main`）
4. 访问 `https://你的用户名.github.io/cross-border-ecommerce`
