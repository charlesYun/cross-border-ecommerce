# 跨境电商公司官网

## 项目概述
现代跨境电商公司官方网站，展示公司品牌、产品和服务，支持多语言，响应式设计。

## 技术栈
- React 18 + TypeScript
- Vite (快速构建工具)
- Tailwind CSS (样式框架)
- React Router (路由管理)
- i18next (国际化)
- Framer Motion (动画效果)

## 功能模块
1. **首页** - 品牌展示、核心价值
2. **关于我们** - 公司介绍、发展历程
3. **产品展示** - 商品分类、详情
4. **服务方案** - B2B/B2C解决方案
5. **新闻动态** - 行业资讯、公司新闻
6. **联系我们** - 联系表单、地图

## 设计特点
- 现代化UI/UX设计
- 响应式布局（支持移动端）
- 多语言切换（中/英）
- 流畅动画效果
- SEO优化

## 开发指南
```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 项目结构
```
src/
├── components/     # 可复用组件
├── pages/         # 页面组件
├── assets/        # 静态资源
├── styles/        # 样式文件
├── utils/         # 工具函数
├── i18n/          # 国际化配置
└── types/         # TypeScript类型定义
```
